# Assets
No image or audio files are shipped (other than `icon.svg`). Characters, enemies, bosses, tiles, backdrops and UI are drawn
with Godot `_draw` calls. Sound effects are synthesised from small recipes (oscillator + noise + envelope); music is
rendered once per track as a looping `AudioStreamWAV` from scales and patterns (background thread at start-up).
All of it is original and generated by the code in this repository.
