# Assets and licences

There are no third-party assets. No image, model, font file, sound or music file is bundled.

- Meshes (terrain, plants, creatures, structures, items) are built in code from primitives (`scripts/gfx/`).
- Textures are procedural shaders (`shaders/`); there are no texture files.
- UI icons and the logo are vector drawings made in code (`scripts/ui/ui_kit.gd`).
- Sound effects, ambience and music are synthesised at startup (`scripts/core/audio_manager.gd`).
- Text uses Godot's built-in default font, which ships with the engine under its own licence (MIT, Godot Engine).
- `icon.svg` is an original drawing.

The project is built with Godot Engine 4.3, MIT licensed.
