# PROJECT STARFALL: The Shattered Sky

A 2D action-adventure for Android and desktop, made with Godot 4.3 (GDScript, GL Compatibility renderer).
You play Kael, an explorer of the Lantern Guild, collecting the seven fragments of the shattered Starheart across
seven regions of Aetheria, each ending in a guardian boss. All art, music and sound are generated by code at runtime;
there are no third-party assets.

## Quick start
- Desktop: open the folder in Godot 4.3 and press Play, or `godot --path .`.
- Android: GitHub Actions workflow `.github/workflows/android-build.yml` runs the automated tests and exports a debug
  APK (`Project-Starfall.apk`, artifact `project-starfall-debug-apk-*`). See `docs/BUILD.md`.

## Controls
| Action | Keyboard | Controller | Touch |
|---|---|---|---|
| Move / climb | A D W S or arrows | left stick | joystick |
| Jump | Space / K | A | JUMP |
| Light attack (3-hit combo) | J / Z | X | ATK |
| Heavy attack | L / X | Y | HVY |
| Dodge / dash | Shift / C | B | DODGE |
| Magic bolt | I / V | RB | MAGIC |
| Ability (Stasis Pulse) | O / B | LB | SKILL |
| Interact | E / Enter | A | USE |
| Heal | H / Q | D-pad down | HEAL |
| Pause / map | Esc, P / M, Tab | Start / Back | pause button |

Keyboard keys can be remapped in Settings > Keys. Touch button size, opacity and handedness are adjustable.

## Layout
`scripts/core` state, save, audio, story, quests. `scripts/world` tiles, level, generator, verifier, stage.
`scripts/entities` Kael, interactables, hazards. `scripts/enemies` the 8 enemy types. `scripts/bosses` the 7 bosses.
`scripts/ui` HUD, menus, touch, cutscenes. `tests/` headless suites listed in `tests/suite.txt`. `tools/` screenshot helpers.
