# Project Wildlands

A 3D open-world survival adventure for Android (desktop optional), built with Godot 4.3 (GDScript, Compatibility renderer).
All models, textures, UI icons, music and sound effects are generated procedurally in code at runtime; there are no third-party assets.

Status: work in progress. See `docs/` for the feature checklist and honest test results as they are produced.
